# Yexora IT Solutions Private Limited - Official Corporate Website

Official Web Application for **Yexora IT Solutions Private Limited** (`https://yexoraitsolutions.com`), based in Indore, Madhya Pradesh, India.

Yexora is an engineering-focused technology company specializing in:
- **Virtual Reality (VR), AR & Spatial Computing**
- **3D Modeling and Visualization**
- **High-Performance Website Development**
- **Scalable Web Application & SaaS Development**

---

## 🛠 Technology Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Library:** [React 19](https://react.dev/) & [TypeScript 5](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **3D Rendering:** WebGL & HTML5 Canvas with fallback support

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm / pnpm / yarn / bun

### Development Server

Run the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### Production Build

Build and lint the production bundle:

```bash
npm run build
npm run lint
```
